## 1. 경쟁 지형 (7개)

| 제품 | 유형 | 핵심 강점 | 약점 / 빈틈 |
|---|---|---|---|
| **Datadog** | 상용 SaaS 종합 | 800+ 통합, 로그·RUM·신서틱·보안까지 풀스택, Watchdog(AI) | 벤더 락인, 호스트/GB 과금 폭발, 자체호스팅 불가 |

| **Grafana (LGTM)** | OSS 스택 | 대시보드 최강, OSS, OTel 친화(Tempo/Loki/Mimir) | 조립 필요, 전용 APM UX 부재, Tempo 트레이스 UX 빈약 |
| **Pinpoint** | OSS (Naver) | 서비스맵·콜스택, 무료 | Java 편중·헤비 에이전트, 구형 UI, OTel 아님 |
| **SigNoz** | OSS, OTel+ClickHouse | **우리와 동일 스택**, APM+로그+메트릭 단일 | 실시간 관제(X-View류) 없음, UX 유틸리티적, 성숙도 |

### 유형 요약
- **락인 상용(DD·NR)**: 강력하지만 비싸고 자체호스팅 불가.
- **한국형 실시간(제니퍼·와탭)**: 실시간 관제가 시그니처지만 락인·구형·Java편중.
- **OSS(그라파나·핀포인트·SigNoz)**: 개방적이지만 조립 필요 / 구형 / 실시간 관제 부재.

**핵심 관찰: "OTel 개방 스택"과 "한국형 실시간 관제 UX"를 동시에 가진 제품은 없다.** SigNoz는 스택은 같지만 실시간 X-View가 없고, 와탭/제니퍼는 실시간은 있지만 락인·구형이다.

## 2. 우리의 차별점 (Why us)

> **한 줄: "오픈 스택(OTel + ClickHouse) 위에 올린, 제니퍼/와탭식 실시간 관제 + 모던 UX. 락인·SaaS 비용 없이 자체호스팅."**

네 개의 뾰족한 강점:

### D1. 개방 스택 × 실시간 관제 (아무도 없는 조합)
- OTel 표준 수신 + ClickHouse 저장 = **벤더 중립·자체호스팅·저비용**(SigNoz/그라파나와 동급 개방성).
- 그 위에 **액티브 트랜잭션 스피드 밴드 · 스크롤 히트맵 · 실시간 X-View**(제니퍼/와탭 시그니처)를 얹음 — **OSS 진영엔 없고, 상용 실시간 진영엔 개방성이 없다.**

### D2. 비용·소유권
- ClickHouse 컬럼스토어 → DD/NR 대비 **저장·조회 비용 수분의 1**, 데이터 소유권 100%.
- 과금 카디널리티 폭발/샘플 강제 없음(로드맵: 샘플링은 선택).

### D3. 모던·응집 UX
- 라이트/다크 토큰 디자인 시스템, 일관 카드 그리드, **드릴다운 모달**(대시보드 흐름 유지), 검색·필터, 서비스맵→리스트 연결.
- 핀포인트/제니퍼의 구형 UI, 그라파나의 조립형, SigNoz의 유틸리티 UI 대비 **완성도·일관성** 우위.

### D4. 바이브코더 온보딩(로드맵)
- env 한 줄로 OTLP 붙이는 초간편 온보딩 → DD/NR의 복잡한 설정, 제니퍼/핀포인트의 무거운 javaagent 대비.

### 우리가 "안" 이기는 것 (정직)
- **폭**: 로그·RUM·신서틱·프로파일링·800통합·알림엔진 = DD/NR이 압도. 우리는 "APM 코어 + 실시간"에 집중.
- **성숙도/생태계**: 상용 대비 운영 실적·통합 부족.
- 전략: **폭으로 붙지 않는다. "개방 스택 위 실시간 관제 + 저비용 + 모던 UX"라는 좁고 깊은 쐐기**로 SigNoz(스택 같음, 실시간 없음)와 와탭(실시간 있음, 락인)의 빈틈을 동시에 노린다.

## 4. 경쟁사별 "우리가 이기는 포인트" (영업 한 줄)

- vs **SigNoz**: "같은 OTel+ClickHouse인데, **실시간 X-View·히트맵과 모던 UX**가 있다."
- vs **Grafana**: "조립 없이 **바로 쓰는 전용 APM UX** + 실시간 관제."
- vs **와탭/제니퍼**: "그 실시간을 **락인·구형 없이, 자체호스팅·저비용**으로."
- vs **Datadog/New Relic**: "필요한 **APM 코어 + 실시간**만, **수분의 1 비용**에 데이터 소유권까지."
- vs **Pinpoint**: "Java 편중·구형 UI 대신 **OTel 다언어 + 모던 UI + 실시간**."
